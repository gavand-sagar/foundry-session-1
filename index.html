Hands-on activity · Session 1

Deploy & test in Chat Playground

  1. Select model: deploy DeepSeek-V4.1-Flash from the Model Catalog.
  2. Set persona: add a system prompt that defines the assistant's rules.
  3. Tune parameters: set temperature to 0.2 for factual answers.
  4. Ground data: upload one PDF for quick file chat.

35–50 min

Data, safety & pricing

File grounding

Upload a PDF in Add your data. Answers then cite the file instead of the model's memory. Switch grounding off in the demo and ask the price question again to see the difference.

Safety filters

Content filters screen prompts and completions for hate, violence, sexual and self-harm content, and also catch jailbreak attempts. Try the last sample prompt.

Pricing

Serverless deployments bill pay-as-you-go per 1K input and output tokens. Track spend in the project's cost view and set token-per-minute quotas.
